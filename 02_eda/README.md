# COVID-19 Dataset Analysis

Анализ датасета COVID-19 по странам мира: исследование заболеваемости, смертности, выздоровления и летальности с помощью визуализаций и статистических методов.

## Структура ноутбука

notebook.ipynb
├── Dataset: COVID-19 Dataset (Kaggle)
├── Import library
├── Open Dataset (country_wise_latest.csv)
├── Dataset Analysis
├── Drop duplicates
├── Bar chart         → Летальность в странах СНГ
├── Line chart        → Динамика выздоровевших (Россия, Беларусь, Украина)
├── Histogram         → Распределение летальности по странам
├── Boxplot           → Летальность по регионам ВОЗ
├── Heatmap           → Корреляции числовых признаков
├── Interactive chart → Новые смерти в России (Plotly)
└── Conclusions

<details> <summary><b>Летальность в странах СНГ (bar chart)</b></summary>
Наибольшая летальность — в Кыргызстане, Молдове и Украине; наименьшая — в Узбекистане, Казахстане и Беларуси. Однако показатель зависит от полноты тестирования: низкая летальность может отражать меньшее число выявленных случаев, а высокая — недостаток тестов или перегрузку системы здравоохранения.

</details><details> <summary><b>Динамика выздоровевших (line chart)</b></summary>
Россия показывает наиболее выраженный рост числа выздоровевших с июня 2020 года. Беларусь и Украина растут медленнее — из-за меньшего масштаба эпидемии и охвата тестирования. Абсолютные значения не всегда отражают относительные успехи: страна с большим населением будет иметь больше выздоровевших даже при худшей динамике.

</details><details> <summary><b>Распределение летальности (histogram)</b></summary>
Большинство стран — в диапазоне 0–4%. Распределение имеет длинный правый хвост: есть страны с летальностью выше 10–15%, что может быть связано с перегрузкой больниц, поздним выявлением случаев или искажениями в статистике.

</details><details> <summary><b>Летальность по регионам ВОЗ (boxplot)</b></summary>
Европа и Африка демонстрируют много выбросов — ситуация внутри регионов неоднородна. Америка имеет самую высокую медиану летальности, что может объясняться возрастной структурой населения, качеством учёта и доступностью медицины.

</details><details> <summary><b>Корреляции (heatmap)</b></summary>
Сильная положительная корреляция между Confirmed и Deaths, а также между Confirmed и Recovered. Это статистическая закономерность, а не причинно-следственная связь: чем больше выявлено случаев, тем больше и смертей, и выздоровлений. Корреляция между Deaths и Recovered слабее — эти процессы не всегда идут параллельно.

</details><details> <summary><b>Новые смерти в России (interactive chart)</b></summary>
К началу июля 2020 года наблюдается снижение ежедневных новых смертей. Однако это ежедневные, а не накопленные значения: общее число умерших продолжает расти. График охватывает только первую волну — после июля 2020 года возможны новые всплески.

</details>
